# Magic Mouse Switch

Switch one Apple Magic Mouse between Windows and macOS with a single keyboard shortcut.

## Download

Go to the **Releases** section and download the version for your operating system.

### Windows

Recommended:
- `MagicMouseSwitch-Setup-1.0.0.exe`

Portable:
- `MagicMouseSwitch.Tray.exe`

Requirements:
- Windows 11
- x64 PC
- Bluetooth

Shortcut:

`Ctrl + Shift + M`

### macOS

Recommended:
- `MagicMouseSwitch-1.0.0.dmg`

Alternative:
- `MagicMouseSwitch-1.0.0-macos.zip`

Requirements:
- Apple Silicon Mac
- Bluetooth

Shortcut:

`Control + Shift + M`


## How it works

1. Install and launch Magic Mouse Switch.
2. Select your Magic Mouse during first-time setup.
3. Use the keyboard shortcut to move the mouse between your Windows PC and Mac.
